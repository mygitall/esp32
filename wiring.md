# ESP32 接线图

## 总体布局

```
                             ┌──────────────────────────────┐
                             │       ESP32 Dev Board         │
                             │                               │
    ┌──────────┐             │  3.3V ────────────────────────┼──────┐
    │  DHT11   │             │                               │      │
    │ 温湿度    │             │  GND ────────────────────────┼──┬───┼──┐
    │          │             │                               │  │   │  │
    │ + VCC ●──┼─────────────┼── 3.3V                        │  │   │  │
    │ - GND ●──┼─────────────┼── GND                         │  │   │  │
    │ OUT   ●──┼─────────────┼── GPIO 4                      │  │   │  │
    └──────────┘             │                               │  │   │  │
                             │  GPIO 2 ──── LED (板载)        │  │   │  │
                             │                               │  │   │  │
                             └───────────────────────────────┘  │   │  │
                                                                │   │  │
                                                                ▼   │  │
                                                              GND ──┘  │
                                                              (共地)   │
                                                                       ▼
                                                                     GND
```

---

## 分步接线

### DHT11 温湿度传感器

```
DHT11          ESP32
┌──────┐      ┌──────┐
│  +   │─────→│ 3.3V │  红色线（VCC）
│  -   │─────→│ GND  │  黑色线（GND）
│ OUT  │─────→│ D4   │  黄色线（GPIO 4）
└──────┘      └──────┘
```

### LED

```
LED 板载（ESP32 GPIO 2），无需额外接线
```

---

## 引脚速查表

| GPIO | 功能 | 接法 |
|------|------|------|
| **GPIO 4** | DHT11 温湿度 | DATA 引脚 |
| **GPIO 2** | LED | 板载，无需接线 |

## 实物连接示意

```
     ESP32                       DHT11
  ┌──────────┐                 ┌──────┐
  │ USB      │                 │  ○ + │──── 红色 ──── 3.3V
  │          │                 │  ○ - │──── 黑色 ──── GND
  │          │                 │  ○out│──── 黄色 ──── GPIO4
  │          │                 └──────┘
  │          │
  │  D4  ●──┼──── 黄色 ────→ DHT11 OUT
  │  3.3V●──┼──── 红色 ────→ DHT11 VCC
  │  GND ●──┼──── 黑色 ────→ DHT11 GND
  └──────────┘
```
