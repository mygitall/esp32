## 分步接线

### 1. DHT11 温湿度传感器

```
DHT11          ESP32
┌──────┐      ┌──────┐
│  +   │─────→│ 3.3V │  红色线
│  -   │─────→│ GND  │  黑色线
│ OUT  │─────→│ D4   │  黄色线 (GPIO 4)
└──────┘      └──────┘
```

### 2. 继电器模块（控制风扇）

```
继电器模块        ESP32
┌──────────┐    ┌────────┐
│  VCC     │───→│ 5V/VIN │  给继电器供电
│  GND     │───→│ GND    │  共地
│  IN      │───→│ D5     │  信号线 (GPIO 5)
│          │    └────────┘
│  COM     │───→ 外部电源 +
│  NO      │───→ 风扇 +
│          │
└──────────┘
```

> 继电器 COM 接外部电源正极，NO 接风扇正极，风扇负极接外部电源负极

### 3. LED

```
LED 板载（ESP32 GPIO 2），无需额外接线
```

---

## 引脚速查表

| GPIO | 功能 | 接法 |
|------|------|------|
| **GPIO 4** | DHT11 温湿度 | DATA 引脚 |
| **GPIO 5** | 继电器 | IN 引脚 |
| **GPIO 2** | LED | 板载，无需接线 |

## 实物连接示意

```
     ESP32                        DHT11
  ┌──────────┐                 ┌──────┐
  │ USB      │                 │  ○ + │─────── 红色 ──── 3.3V
  │          │                 │  ○ - │─────── 黑色 ──── GND
  │          │                 │  ○out│─────── 黄色 ──── GPIO4
  │          │                 └──────┘
  │          │
  │          │                 继电器
  │  D4  ●──┼──── 黄色 ────→ DHT11 OUT    ┌──────────┐
  │  D5  ●──┼──── 绿色 ────→ 继电器 IN    │ VCC ○──── 5V
  │  5V  ●──┼──── 红色 ────→ 继电器 VCC  │ GND ○──── GND
  │  GND ●──┼──── 黑色 ──┬─→ DHT11 GND  │ IN  ○──── GPIO5
  │  GND ●──┼──── 黑色 ──┤─→ 继电器 GND  │          │
  └──────────┘           │              │ COM ○──── 电源+
                          │              │ NO  ○──── 风扇+
                          └──────────────┼───────────┘
                                    共地 GND
```
